# Guide de l'espace de gestion Mawazo

Adresse : **votre-site/admin** (à ajouter à l'écran d'accueil du téléphone : menu du navigateur > « Ajouter à l'écran d'accueil »).

Vous restez connectée 30 jours sur votre téléphone. Pour quitter : *Menu > Se déconnecter*.

## Le quotidien

En bas de l'écran du téléphone : **Accueil**, **Rendez-vous**, **Commandes**, **Menu**.

### Rendez-vous
- Chaque demande faite sur le site arrive ici **et** sur WhatsApp, avec une référence (ex. `R-7K3QF`).
- Ouvrez un rendez-vous, puis touchez le statut : **confirmée**, **honorée** (la cliente est venue), **absente**, **annulée**.
- **Répondre sur WhatsApp** ouvre la conversation avec la cliente, message déjà commencé.
- Un rendez-vous pris par téléphone ou au salon : **Noter un RDV**.

### Commandes
- Même principe. Quand la cliente a payé par mobile money, saisissez la **référence de la transaction** puis passez la commande à **payée**.
- Pensez à baisser le **stock** du produit vendu (*Produits*).

## Modifier le site

Chaque écran a un gros bouton **Enregistrer** en bas. Le site est mis à jour immédiatement.
Si la connexion coupe, votre saisie reste à l'écran : appuyez de nouveau sur **Enregistrer**.

| Je veux… | Où |
|---|---|
| changer un prix, une description, une photo de prestation | *Prestations* |
| ajouter / modifier un produit, son stock, ses pointures ou longueurs | *Produits* |
| créer une promotion (Mardi Promo, Pack Mariée…) | *Promotions* |
| ajouter une transformation avant / après | *Avant / Après* |
| publier l'avis d'une cliente | *Avis clientes* |
| écrire un article | *Blog* |
| changer le texte ou la photo de l'accueil | *Textes et images du site* |
| changer le numéro WhatsApp, les e-mails, les horaires, Instagram, les numéros mobile money | *Coordonnées et paiement* |

### Photos
- Touchez **Choisir une photo** : vous pouvez prendre une photo ou choisir dans la galerie.
- Les photos sont allégées automatiquement avant l'envoi (économie de données).
- Pour un produit : la **première** photo est celle du catalogue. Les flèches changent l'ordre.

### Masquer plutôt que supprimer
Décochez **Publier sur le site** pour cacher une prestation ou un produit sans le perdre. La suppression est définitive et demande une confirmation.

### Ordre d'affichage
Dans les listes, les flèches **haut / bas** changent l'ordre sur le site.

## Promotions

1. **Type** : *Pourcentage* (ex. -20 %), *Montant fixe* (ex. -5 000 FC) ou *Affichage seul* (annonce sans changer les prix, pour une offre négociée au salon).
2. **Ce qui est concerné** : tout, une catégorie, ou des prestations / produits choisis.
3. **Jours** : cochez *Mardi* seul pour le Mardi Promo. Rien de coché = tous les jours.
4. **Période** : dates de début et de fin, facultatives (heure de Kinshasa).
5. **Bandeau** : « Bandeau en haut du site » affiche « Aujourd'hui : … » les jours concernés.

L'**aperçu des prix** montre l'effet avant d'enregistrer. Si deux promotions touchent un même article, la plus avantageuse pour la cliente s'applique (jamais les deux).

## Avis clientes
Uniquement de vrais avis, **avec l'accord de la cliente** (case obligatoire pour publier). Écrivez le prénom et l'initiale : « Nadège K. ».

## Comptes
- *Mon compte* : changer votre mot de passe.
- *Utilisateurs* (gérante et Lean Market) : ajouter une employée, réinitialiser un mot de passe oublié, désactiver un compte.
